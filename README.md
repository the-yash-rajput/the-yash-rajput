## 📌 Featured work

| Project | What it is |
| --- | --- |
| **[AgentCrafter](https://github.com/the-yash-rajput/AgentCrafter)** | Visual AI workflow builder on LangGraph. React Flow canvas + Django/DRF backend; graph definitions live in Postgres and compile to a runnable graph on execution. Sandboxed inline-Python nodes, conditional and LLM-routed edges, SSE run streaming, Langfuse tracing. |
